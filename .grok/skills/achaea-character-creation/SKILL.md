# Achaea — character creation

Companion to `mud-skill` and `mud-character-creation`. Achaea is a separate
product from Discworld MUD — use only **public** site/wiki help; never invent
login hosts or credentials.

**Sources (link-out):**

- [Races overview](https://www.achaea.com/races)
- [Newbie guide](https://www.achaea.com/newbie-guide)
- [HELP races in Achaea (web mirror)](https://www.achaea.com/game-help/?what=races-in-achaea)
- [AchaeaWiki newbie guide](https://wiki.achaea.com/Newbie_Guide)

## LOCKED — Creation flow (Nexus / web)

Public newbie material describes: **Play Now** on the Achaea site → create a
new character (or log in) → guided **newbie introduction** (~1 hour tutorial:
commands, gear, movement, story). Character is shaped by **gender, race, class,
and organisations** (city, house, divine order) over time.

## LOCKED — Race (14 playable)

Public lists include: Dwarf, Fayad (Fae), Human, Mhun, Troll, Tsol'aa, Atavian,
Horkval, Grook, Rajamala, Xoran, **Siren (female only)**, **Satyr (male only)**,
and Tash'la. No single "best" race for a class — all viable; pick for roleplay
and racial traits (`HELP <racename>` in-game).

- **First reincarnation is free** (change race once at no credit cost).
- **Racial specialisation** at **level 10** after joining a class — shifts stat
  distribution (+2 one stat, -1 another per public help).

## LOCKED — Class, city, house (post-creation)

- Class choice gates some **city** residency (public wiki: e.g. nature classes
  toward Eleusis, devotion-users toward Targossas — read current help).
- Houses and Certimene / Delos flow are mid-newbie steps (wiki newbie guide) —
  human confirms before spending lessons or travelling.

## LOCKED — Agent discipline

1. Connection details only from the human (Achaea client / Nexus — not Discworld
   telnet defaults).
2. Use `HELP`, `HOW DO I`, `WHERE IS` patterns in-game per public guides.
3. NEWBIE channel and Romeo/Juliet guides for questions — human approves spam.

## UNKNOWN

- Live class balance or "best" race for a build — ask experienced players in-class.
- Credit/crown economy — see Achaea billing docs; not harvested here.
