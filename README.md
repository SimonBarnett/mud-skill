# mud-skill

Fleet agent skill pack for **MUD play**, with a first focus on **Discworld MUD**
(classes, guilds, game rituals). Not a game client rewrite — harvest and
structure playbooks agents can load under `~/.grok/skills`.

**MRB home:** see open `feature-request` issues.  
**Chair:** Bob only for ready for human UAT.
